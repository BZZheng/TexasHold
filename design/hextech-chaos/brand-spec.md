# 海克斯大乱德视觉资产规范

## 设计方向

牌桌延续现有私人俱乐部风格。人物、技能、觉醒和选择阶段使用可爱卡通贴纸语言。两个视觉层通过共同的暖象牙、深棕描边和哑金连接。

## 色彩

| 语义 | 色值 | 使用范围 |
| --- | --- | --- |
| 牌桌背景 | `#0d130f` | 页面和牌桌外围 |
| 牌桌翡翠 | `#27533e` | 椭圆牌毡 |
| 原有哑金 | `#d9ad55` | 当前行动、筹码、目标 |
| 卡通纸张 | `#f8f0df` | 普通技能卡、人物卡 |
| 卡通描边 | `#493e33` | 卡面轮廓和插画轮廓 |
| 欺诈珊瑚 | `#e8896f` | 欺诈和高风险技能 |
| 防御鼠尾草 | `#89b99a` | 防御和经济技能 |
| 情报雾蓝 | `#7fafc6` | 情报技能 |
| 金色海克斯 | `#f2c45e` | 稀有卡框和确认按钮 |
| 觉醒灰紫 | `#a48bc2` | 觉醒卡与状态 |

新增色只允许出现在海克斯层。标准下注按钮继续使用现有牌桌色彩。

## 形状

- 原有面板圆角 14 px。
- 人物与技能卡圆角 16 px，深棕 2 px 外框。
- 卡通主按钮圆角 10 px，允许 3-4 px 实体下沿表达按压。
- 不使用玻璃拟态、霓虹外发光和大面积渐变。

## 插画

- 原创虚构人物，不默认映射真实人物长相。
- 成年角色，Q版比例但不幼儿化。
- 半身或腰部以上透明背景立绘。
- 深棕粗轮廓、平涂、轻纸张纹理。
- 128 px 显示尺寸仍能辨认表情和职业道具。
- 每个角色需要普通立绘和觉醒立绘各一张。
- 每个公共技能需要一张透明背景贴纸图标，建议 512 x 512 源文件。
- 插画内部禁止文字，所有名称由 HTML 渲染。

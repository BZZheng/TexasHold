# 嗡嗡文 · 月刃行者开发合同

状态：已接入共享人物目录、服务端权威状态机与生产人物控制轨；本文件保留为实现和验收合同。

## 目标

嗡嗡文是翻牌后信息追猎人物。玩法只读取服务端允许展示的一张牌，不改变牌堆、下注顺序、底池或筹码总量，也不复用鸭哥、奇玩的换牌能力。

## 权威规则

- 资源：月痕，初始 0，上限 3，公开。
- 获取：仅翻牌圈或转牌圈。面对其他玩家至少 2BB 的手动主动下注或加注，嗡嗡文手动跟注、加注或全押且实际新增投入至少 2BB；每手最多 1 月痕。
- 主动：消耗 2 月痕，每手一次。仅在自己行动、面对本街最后主动进攻者且待跟注大于 0 时发动。
- 结果：服务端从目标的两张“展示牌”随机取一张，仅向嗡嗡文返回，保留到本街结束。真实底牌永不进入公共事件或其他玩家视图。
- 伪装：假弱、假强等遮罩先于人物引擎执行。嗡嗡文不会获知展示结果是否被伪装；遮罩的使用由服务端作弊审计记录。
- 觉醒：5 手牌触发追刃，其中至少 1 次在转牌圈，并在摊牌击败 1 名该手追击的进攻者。
- 满月双刃：觉醒后，查看牌的紧接下一次行动若为至少 2BB 的合法完整加注或全押加注，返还 1 月痕；资源上限仍为 3。

## UI 三轨合同

人物控件只进入 `control rail`，不得覆盖 `table zone` 或 `hand rail`。

- 桌面固定高度：214px。
- 320–639px 固定高度：342px。
- 工作区内部可滚动；帮助、确认、私密结果复用同一块区域。
- 主操作固定左槽，取消固定右槽；状态切换不交换按钮位置。
- 私密牌面只渲染 `state.reveal`，组件不得读取其他玩家的 `cards`、`hand` 或候选字段。
- 桌面支持点击与键盘；所有移动端按钮至少 44×44px。

## 已落地的接线边界

1. `WENGWENGWEN_RULES` 与 `WENGWENGWEN_CHARACTER` 已注册进 `shared/hextech.js`；海克斯人数上限为 8，八人目标为 12,400。
2. 所有街道、行动者、投入、BB、完整加注和展示牌均由服务端从牌局快照派生；客户端只提交命令 ID。
3. `gameAction` 前后快照调用 `afterPokerAction`；客户端不能提交 `displayedCards`、`targetUserId`、`isFullRaise` 或 `investment`。
4. 发动时先通过公共技能效果引擎取得展示牌遮罩，再调用人物引擎；公共 socket 事件不包含牌面或 `masked` 标志。
5. `afterStreet` 清理私密结果；`settleHand` 使用服务端边池 provenance 判断是否真正击败被追击目标。
6. `#view` 只把人物引擎的本人私密结果合并给本人，其他客户端的 `reveal` 为 `null`。
7. 生产 `HextechCharacterControl` 使用固定人物控制轨；独立组件只保留为可隔离验收稿，不进入另一套可变高度布局。
